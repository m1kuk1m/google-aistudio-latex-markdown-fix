# Google AI Studio - 数式＆Markdownレンダリング修正

[Google AI Studio](https://aistudio.google.com/) 向けに開発された軽量な Tampermonkey ユーザースクリプトです。複雑な LaTeX 数式の途切れ、Markdown テーブル内での分割行列の縦線欠落、ストリーミング表示の競合、ドル記号の数式誤認識、生化学アスタリスク分割、および各種レイアウト崩れを修正します。

---

## 背景と解決される主な課題

Google AI Studio で複雑な数学的表現や Markdown を含む出力を生成する際、標準のウェブUIでは以下のようなレンダリングの問題が発生します：

1. **Markdown テーブル内の分割行列パイプ（`|`）の衝突と列消失**：
   GitHub Flavored Markdown (GFM) はパイプ文字 `|` を表の列区切りとして処理します。LaTeX の `array` 環境（例：`\begin{array}{cc|c}`）で縦の分割線が使われている場合、パーサーがこれを新しい列と誤認し、数式が途中で切れたり後続の列（比較表の2つ目の行列など）が完全に消失してしまいます。
2. **リスト記法による複数行 LaTeX 数式の分断・未描画**：
   筆算や錯位相消法など、行頭が `+ & ...` や `- & ...` で始まる複数行数式（`\begin{array}`、`\begin{aligned}`）を出力した際、CommonMark パーサーが行頭の記号を箇条書きリストと誤認識して `<p>` と `<ul><li>` に数式を分断してしまい、プラス記号が黒丸に化けて描画不能になる問題を修正します。元の LaTeX 環境キャッシュによる照合と兄弟 DOM 要素の結合機構により、消失した記号を補完して完全な数式ブロックを再構築します。
3. **プレーンテキストのドル記号（`$` / 金額表記）の数式誤認識と書式崩れの修正**：
   モデルがドル金額（例：`（$19.99/月）和 **Google AI Ultra**（$99.99/月起）` や `$2/$10` など）を出力した際、標準パーサーが右側の閉合規則判定の不備からインライン数式として誤判定し、ドル記号が消失したり文字が斜体化して太字アスタリスクが露出する問題を解消します。誤認されたドル記号と本文を元の位置で復元し、内部の `**` 太字スタイルを連動して修復します。
4. **CJK（日中韓）句読点と Markdown 太字の不整合**：
   全角句読点に隣接する太字アスタリスク（`**太字**`）が適切に解析されず、記号がそのまま本文に露出してしまう問題を解消します。
5. **疑似コードブロックの解体とインデント保護**：
   リスト内のインデントされた通常テキストが誤ってコードブロックとして取り込まれてしまう現象を解体し、見出しや数式を正常に展開します。
6. **チルダ数値区間（~）の取り消し線誤変換防止**：
   数値区間（例：`5%~16%` や `3~5回`）が取り消し線（`<del>` / `<s>`）に誤変換されるのを防ぎます。
7. **生化学・タンパク質アスタリスク命名の太字分離修正**：
   アスタリスクを含む命名（`A\beta*56`、`CYP2D*6` など）が太字装飾時に誤って分離され、アスタリスクが露出する不具合を修復します。
8. **緊密リスト（Tight List）内の複数行数式未描画**：
   リスト項目内に含まれる複数行 LaTeX 数式がスキップされ、KaTeX が適用されない不具合を修正します。
9. **モバイル環境における横長数式スクロールの跳ね返り防止**：
   スマートフォン等のブラウザ（Firefox Android など）で幅の広い数式を横スクロールした際、仮想スクロールによるアンロードと不自然なバウンス動作を防ぎます。
10. **ストリーミング生成時のタイミング競合と上書き防止**：
    モデルのストリーミング出力中（`fetch` / `streamGenerateContent`）、未完了のブロックに対して KaTeX が早期実行されることで、テキストのちらつきや出力内容の不要な上書きが生じるのを防ぎます。

## インストール方法

### 前提条件
- お使いのブラウザに **Tampermonkey** などのユーザースクリプト管理拡張機能がインストールされていること（Chrome, Edge, Firefox, Firefox for Android に対応）。

### GitHub から直接インストール
1. 以下の直リンクをクリックしてインストール画面を開きます：
   - [google-aistudio-latex-markdown-fix.user.js をインストール](https://raw.githubusercontent.com/m1kuk1m/google-aistudio-latex-markdown-fix/main/google-aistudio-latex-markdown-fix.user.js)
2. Tampermonkey のインストール確認画面が表示されたら、**「インストール」** をクリックします。
3. [Google AI Studio](https://aistudio.google.com/) を開くか、既存のタブを再読み込みすると有効になります。
